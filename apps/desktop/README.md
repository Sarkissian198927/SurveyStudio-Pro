# Native Anwendung

Tauri-2-Quellcode für denselben React-Editor mit lokalem SQLCipher-Store. Entwicklung: `pnpm --filter @surveystudio/desktop dev`; Installerbuild: `pnpm --filter @surveystudio/desktop exec tauri build -- --locked`. Rust und die plattformspezifischen Tauri-/SQLCipher-/OpenSSL-Buildvoraussetzungen müssen installiert sein. Der manuell auslösbare Windows-Workflow liegt unter `.github/workflows/desktop.yml`; er prüft vor der Artefaktbereitstellung die Installation und den Fensterstart. Siehe `docs/DESKTOP_0_4_0.md`.

`packages/desktop-store` persistiert Projekte, Entwürfe, Versionen, Antworten, Kommentare und Outbox. Native SQL-Kommandos verwenden gebundene Parameter. Ein zufälliger Schlüssel wird im Betriebssystem-Schlüsselbund aufbewahrt, SQLCipher verschlüsselt die Datenbank. Fehlender Schlüsselbund oder fehlender Schlüssel einer vorhandenen DB führt zum Fehler statt Klartextfallback. Initialisierung verwendet einen exklusiven Dateilock. Die Datenbankdatei allein genügt nicht für eine Wiederherstellung; sichere Schlüssel-/Schlüsselbundsicherung ist erforderlich.

Geprüft: echte SQLite-Dateipersistenz über Schließen/Öffnen, Revision/Retry/Kommentare/CSV/Outbox sowie native SQLCipher-Dateiverschlüsselung, richtiger/falscher Schlüssel und Initialisierungssperre unter Linux. Nicht geprüft: tatsächlicher OS-Schlüsselbundanbieter, vollständige Windows-GUI-Abnahme, Signierung oder vollständiger nativer Offline-GUI-Ablauf. Installer-/Start- und Schlüsselbundprüfungen erfolgen zusätzlich in der Windows-Pipeline. Persönliche lokale Veröffentlichungen, XLSX/PDF, Sync-Pull, automatische Synchronisation und Lösch-Tombstones fehlen. HTTPS-Push und Gerätewiderruf sind vorhanden.
